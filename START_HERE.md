## 🎓 Key Concepts Explained

### Push Notifications
**Simple**: When incident is assigned, responder gets a notification on phone
**Technical**: Firebase Cloud Messaging (FCM) + WebSocket + SMS fallback
**Test**: Create incident → Assign to unit → Check for notification

### PDF/Excel Export
**Simple**: Download a report of incidents as an Excel spreadsheet or PDF
**Technical**: Query database → Transform to rows → Generate file → Send to browser
**Test**: Go to Incident Archive → Click Export → Verify file downloads

### System Settings
**Simple**: Admin configures email server and API credentials
**Technical**: Web form → Backend API → Encrypted database storage
**Test**: Go to Admin Settings → Change SMTP host → Verify password encrypted

### Offline Incident Queue
**Simple**: Reporter can submit incident even without internet
**Technical**: Save locally → Detect connectivity → Auto-sync when online
**Test**: Turn off WiFi → Submit incident → Turn on WiFi → Verify syncs
