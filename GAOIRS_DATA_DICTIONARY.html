Enumeration Values Reference
All enum types with their valid values.

Role (USER.role)

ADMIN - Full system access, incident management, approvals
RESPONSE_UNIT - Receive assignments, submit reports, view incidents
REPORTER - Create incidents, view own reports, limited access

UnitType

FIRE - Fire Department (BFP)
POLICE - Police Force (PNP)
MEDICAL - Ambulance/Medical Response
DRRMO - Disaster Risk Reduction Management Office
BARANGAY - Barangay Health/Public Order Unit

UnitStatus (RESPONSE_UNIT.availability_status)

AVAILABLE - Ready to receive assignments
BUSY - Currently responding (cannot accept new assignments)
OFFLINE - Not operational (equipment maintenance)
ON_BREAK - Personnel on break (available shortly)

IncidentStatus

REPORTED - Initial report received, pending verification
VERIFIED - Admin confirmed incident legitimacy
RESPONDING - Units en route to scene
ON_SCENE - Units arrived and responding
RESOLVED - Incident handled, units completing work
FALSE_ALARM - No actual emergency, incident cancelled
CLOSED - Incident complete, marked for archive

Severity & Priority (INCIDENT)

Severity - LOW - Minor incident, limited immediate impact
Severity - HIGH - Significant incident with multiple casualties/property damage
Severity - CRITICAL - Life-threatening, major disaster, mass casualty
Priority - LOW - Non-urgent, can wait for availability
Priority - MEDIUM - Standard priority dispatch
Priority - HIGH - Urgent, dispatch nearest unit immediately
Priority - CRITICAL - Life-threatening, all available units dispatch

AssignmentStatus (INCIDENT_ASSIGNMENTS)

PENDING - Awaiting unit acknowledgment
ACCEPTED - Unit accepted, preparing to respond
REJECTED - Unit rejected (unavailable, etc.)
RESPONDING - Unit en route to incident
ON_SCENE - Unit arrived and actively responding
RESOLVED - Unit completed response actions

AlertChannel (NOTIFICATIONS)

SMS - Text message via Twilio
EMAIL - Email via Nodemailer SMTP
DASHBOARD - In-app notification in web/mobile UI
PUSH - Push notification via Firebase Cloud Messaging

DeliveryStatus (NOTIFICATIONS)

PENDING - Queued for sending
SENT - Successfully sent to recipient
DELIVERED - Confirmed received by recipient
READ - Recipient opened and read notification
FAILED - Delivery failed (invalid number, network error)

ReportStatus (POST_INCIDENT_REPORTS)

PENDING - Submitted, awaiting admin review
UNDER_REVIEW - Admin is currently reviewing
APPROVED - Admin approved, marked as official record
REJECTED - Admin rejected due to inaccuracies/issues

ReportType & FileFormat (GENERATED_REPORTS)

INCIDENT_SUMMARY - Summary statistics of incidents in period
AREA_REPORT - Incidents grouped by barangay/geographic area
RESPONSE_TIME - Response time metrics and KPIs
FULL_EXPORT - Complete incident data export with all details
PDF - Adobe PDF format (charts, summaries, professional layout)
EXCEL - Microsoft Excel spreadsheet (detailed data, formulas)
CSV - Comma-separated values (raw data export)
