📋 Schema Overview

Database: PostgreSQL with PostGIS extension

Primary Key Pattern: UUID (auto-generated)

Timestamp Pattern: created_at (auto), updated_at (auto), specific datetime fields for tracking

Core Models (4)

User: Authentication & authorization
Incident: Core business entity
ResponseUnit: Emergency responders
Barangay: Geographic divisions (PostGIS)

Process Models (6)

IncidentAssignment: Unit-to-incident dispatch
IncidentStatusLog: Audit trail
PostIncidentReport: After-action reports
Evidence: Photos/media storage
Notification: Alert distribution
GeneratedReport: PDF/Excel exports

✅ Key Database Features

  • PostGIS Integration: Barangay boundaries stored as GeoJSON polygons for geospatial queries
  • Audit Trail: INCIDENT_STATUS_LOG & SYSTEM_AUDIT_LOGS track all changes with user attribution
  • Smart Assignment: Incidents automatically routed to units based on type & severity
  • Multi-channel Notifications: SMS, Email, Push (FCM), Dashboard alerts
  • Complete Lifecycle Tracking: Incident creation → assignment → on-scene → resolution
  • Evidence Management: Photos/media linked to incidents via Cloudinary
  • Reporting & Analytics: PDF/Excel exports with customizable filters
  • Configuration Management: Encrypted system settings for sensitive data
